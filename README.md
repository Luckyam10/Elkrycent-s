# Our Days — Family Journey v2

A redesigned mobile-first family memory website with a **morning / countryside / warm scrapbook** aesthetic.

Login:
family / memories

Features:
- warm morning countryside visual language
- animated sun, clouds and hills
- responsive mobile/desktop layout
- interactive destinations
- place-specific memory sheets
- timeline
- photo wall
- video slot
- login/logout
- no build step

Put real photos in `assets/images/` and videos in `assets/videos/`.

The included login is only front-end convenience and is not secure authentication. For genuinely private family content, use real authentication/private hosting.
